# Premium Portfolio (Vite + React + TypeScript + Tailwind)

Run locally:

```bash
npm install
npm run dev
```

Type-check (optional):

```bash
npm run typecheck
```

Build for production:

```bash
npm run build
npm run preview
```

Deploying:

- Vercel: `vercel --prod` or connect your repo and use the default Vite build settings.
- Netlify: Create a new site, set the build command to `npm run build` and publish directory to `dist`.

The app uses Tailwind CSS and `lucide-react` for icons.
